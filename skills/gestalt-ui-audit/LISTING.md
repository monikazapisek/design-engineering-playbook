## Publishing fields

**Name**

```text
gestalt-ui-audit
```

**Tagline**

```text
Find where the groups people see in your frame differ from the structure you designed, across nine Gestalt principles.
```

**Description**

```text
People group what is close, alike, enclosed, or connected, whether or not those elements belong together. Select one frame and the skill first looks at it as the user doing the frame's main task, then reads its layers, maps the groups people will perceive against the structure the frame intends, and scores proximity, similarity, common region, uniform connectedness, continuity, closure, figure/ground, common fate, and Prägnanz. Each finding names the layers involved and a concrete layout fix. It reports first, marks anything a static frame cannot show as not assessed, and asks before adding comments to the canvas.
```

**Category:** Critique

**Cover text**

```text
See the groups your users see.
```
